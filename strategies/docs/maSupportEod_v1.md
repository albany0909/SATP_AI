## 1. 개요

**SMA5 상향 돌파** 이후, 눌림에서 **약음봉 또는 십자/소형몸통 + 5일선 지지**가 나오면 **종가 근접 시장가 매수**한다.
보유 중 **종가(장중 현재가)가 SMA5를 이탈**하면 **전량 매도**한다.
이평선터치(`maTouchScale_v1` / MTS01)와 **별도 알고리즘코드(MSE01)** 로 관리한다.

### 당일 봉 데이터 출처 (실전)

당일 1분봉(`AI_MIN_STK_PRC`)은 **장마감 배치(15:34~)** 에서 적재되므로 15:18 매수 창에는 DB에 없다.
0B 실시간 구독은 관심(`USE_TRADE=Y`)만이라 MSE01 대상 대부분은 현재가도 오지 않는다.
그래서 장중에는 **ka10001**(주식기본정보)로 시가·고가·저가·현재가·**누적거래량**을 종목당 1회 받아 당일 봉을 만든다.

| 순서 | 출처 | 비고 |
|---|---|---|
| 1 | 당일 1분봉 | 장마감 후 재검증·복기 |
| 2 | **ka10001** | 장중 매수·매도 창 (`utils/liveOhlcSnap.py`) |
| 3 | 당일 일봉 | 장마감 확정 후 |

- **돌파 이력이 없거나 보유 중인 종목은 조회하지 않는다** (당일 봉이 필요 없으므로 TR 절약)
- 종목당 스냅은 8초 캐시
- **한 폴링에 20종씩 나눠** 조회하고, 다음 폴링은 이어진 위치부터 본다 (회전). 한 폴링에 전 종목을 몰지 않는다
- 호출 한도는 `utils/trRateLimit.py` **공용 게이트**로 지킨다. 같은 ka10001 을 관심툴팁(`stkWatchTipSnap`)도 쓰므로, 모듈별로 따로 재면 합쳐서 초과한다. 모의 = 같은 TR 1초 1회, 실전 = 조회 TR 합산 1초 4회(한도 5회에서 여유 1회)
- 폴링 1회는 **최대 40초** 안전망. 매수 창이 2분뿐이라, 같은 창에서 매도 스캔(SMA5 이탈)도 다시 돌 기회를 준다
- **창이 닫히면 폴링 중간이라도 즉시 중단**한다. 동시호가(15:20) 이후로 주문이 넘어가지 않게 한다
- 2분 창에서 평가 가능한 종목은 **약 110종**이 물리적 상한(120초 ÷ 1.05초)이다. 현재 대상 약 57종은 창 안에서 전 종목을 1~2회 본다. ka10016 유니버스가 100종을 넘어가면 일부는 그날 평가되지 못한다

## 4. 매수 시점

1. **돌파 이력**: 과거 어느 날 종가가 SMA5를 **상향 돌파**했을 것. **당일 돌파 봉에서는 매수하지 않음**
2. 미보유 상태에서, 당일 봉이 **약음봉 또는 십자/소형몸통**이고 **SMA5 지지**이며 **당일 거래량 < 최근 3개 양봉 거래량(최솟값)** 일 때 매수
3. **실전(MSE01)**: **15:18~15:20(미만)** 장중, 조건 충족 시 **시장가**. 장마감 **동시호가(15:20) 직전까지** — 연속거래 마지막 2분만 본다 (구간 내 반복 재확인)
4. **백테스트**: 당일 **종가** 체결 가정
5. 약음봉: 종가 &lt; 시가, 몸통(시가−종가)/시가 ×100 ≤ `weakBearMaxPct`(기본 2.5)
6. 십자/소형몸통: |종가−시가|/시가 ×100 ≤ `dojiMaxPct`(기본 0.5) — 소형 양봉 포함
7. SMA5 지지: 저가 ≤ SMA5 ≤ 종가
8. **거래량**: 당일 거래량 &lt; 직전 **양봉(종가&gt;시가) 3일** 거래량의 **최솟값**. 양봉 3일을 못 찾거나 당일 거래량이 없으면 매수 안 함. 실전 15:18~15:30 창은 **그 시점 누적 거래량**
9. 수량 = `floor(buyAmtWon / 체결가)` (최소 1주)
10. 종목당 **1포지션** (청산 전 추가매수 없음)
11. 실전 매수 OHLC 출처 (2절 참조): **당일 1분봉** → 없으면 **ka10001**(시가·고가·저가·현재가·누적거래량). 1분봉이 있으면 **현재가로 종가를 덮어쓰지 않음** (약음봉이 1틱에 사라지지 않게). ka10001 봉은 종가가 곧 현재가이므로, **0B 구독 종목은 실시간 현재가로 종가·고저를 보정**한다

돌파 후 미보유인데 종가 &lt; SMA5 이면 돌파 이력 리셋.

조건 미충족은 매수 창이 끝나면 `BUY_SKIP` 으로 종목당 1건 복기한다 (`NOT_BEAR` / `NO_SMA5_SUPPORT` / `NO_BREAKOUT` / `VOL_GE_BULL` / `VOL_NO_BULL` 등).

## 7. 백테스트 가정

- 원천: `AI_DAY_STK_PRC` 일봉
- SMA5: 전일까지 종가 5개 평균 (당일 종가 미포함)
- 진입·청산 체결가: 당일 종가
- 수수료 0
- 유니버스: 전거래일 16시 ka10016 52주 신고가 편입. 이후 종가>SMA20 유지, 종가≤SMA20 제외

## 8. 실전·복수 알고리즘

- 원장·복기·설정은 `algCd` 단위로 분리 (MTS01 / MSE01)
- 실시간 엔진: `watchRtMonitor` → `startMaSupportEodLive`
- 장중 당일 봉 조회: `utils/liveOhlcSnap.py` (ka10001, 종목당 8초 캐시·TR 1초 간격)
- 매도 창(15:18~15:20)과 매수 창(15:18~15:30)이 겹치면 **같은 폴링에서 매도를 먼저** 한다. 같은 날 청산 뒤 재매수는 청산 봉에서 금지
- 동일 종목 동시 보유 시 모의계좌 잔량은 공유되므로 `crossAlgBuyGuard` 로 신규매수를 막음
