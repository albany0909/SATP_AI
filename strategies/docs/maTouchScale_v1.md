- **stratId**: `maTouchScale_v1`

- **권장 타임프레임**: 일봉 SMA + 1분봉(검증) / 실시간 체결(0B)

- **실주문**: 모의만 (`paperOnly`). `USE_TRADE` 자동 ON 없음

## 1. 개요

전 거래일 16시에 확정된 대상(`USE_TRADE=Y`)을 놓고, **SMA 20** 에 위에서 내려와 닿으면 매수 대기에 넣는다.
터치 즉시 사지 않고, **당일 거래에 한해** 터치 이후 **3분봉이 SMA20을 종가 돌파하고 양봉**(종가>시가)으로 끝나면
그 이평 **인근 호가 지정가**로 산다. 지정가가 **10분 안에 안 체결**되면 잔량을 취소하고 **시장가로 바꾸지 않는다**.
취소 이력은 매매창 거래로그에 남긴다.
틱이 이평을 잠깐 뚫는 것만으로는 사지 않는다.
1차 익절은 평단 **+1.2%** 에서 보유 **30%**, 2차는 **+2%** 에서 보유 **30%**,
3차는 2차 후 잔량이 **+4% 이상**이면 보유 **50%**, 4차는 **+7% 이상**이면 잔량 전량한다.
하드스탑 **-2%**(1·2차 전), **1차 또는 2차 이후 잔량**은 평단 **0%(본전)** 이하면 즉시 전량한다.
**수익 중**이고 일봉 RSI14가 **70 이상**이면 **잔량 전량** 청산한다 (장중, 부분익절보다 앞).
**당일 매수분이 15:18에 수익이 아니면 전량**한다 (다음날 시초 갭을 넘기지 않기 위함).
**매일 15:15부터** 평단 **0% 이상 3% 이하**이면 전량한다 (손실은 제외, 3% 초과는 보유).
**전량 청산한 종목은 당일 재매수 금지**다.
대상 등록(전날)과 매매 판정(당일)은 분리되어 있다.

## 2. 대상종목 (Universe) — 전날 16시 확정

**매매 당일의 대상은 전 거래일 16:00 에 확정된다.** 장중에 대상이 늘어나지 않는다.

| 항목 | 내용 |
|------|------|
| 시각 | 거래일 **16:00** (~18:30 재시도, 1일 1회) |
| 원천 | `ka00198` 실시간조회순위 **당일누적** |
| 편입 조건 | ① **코스피/코스닥** ② 매차 최소금액으로 **1주 이상** ③ **조회순위 상위 20 ∪ 거래대금 상위 30** (중복 제거) |
| 최대 | 합집합 최대 **약 50종** (`rankMax` 20 + `maxTrdePrcaRank` 30) |

| 구독 | 다음 장 시작 시 `watchRtMonitor` 가 0B 등록 (등록 즉시 REG 아님) |

- **시장 필터**: 코스피·코스닥만. ETF·코넥스·외국주(Reg.S 등)는 제외한다.
- **수량 필터**: 매차 금액으로 `floor(금액/종가) < 1` 이면 제외한다.
- **합집합**: 예전처럼 순위∩대금이 아니라, 순위 20과 대금 30을 **모두** 넣고 중복만 뺀다.
- 양봉(종가>시가) 필터는 쓰지 않는다.
- **기존 관심 유지/제외**: 현재가 > SMA20 이면 유지. **이틀 연속 음봉(종가<시가)이면서 종가 ≤ SMA20** 이면 관심·관리에서 제외. 하루만 이탈하거나 양봉이면 유예 유지.
- **매일 전량 교체**: 전날 대상 중 새 목록에 없는 종목은 관리·관심에서 해제한다.
- **미청산 보유는 예외**: 원장(`AI_STRAT_ORD_LEDGER`)에 잔량이 남은 종목은 교체에서 제외해 다음날에도 감시·청산을 이어간다.
- 장중 15분 순위 편입, EMA/SMA 정배열 유지 규칙은 **사용하지 않는다**.
- 배치 ID `maTouchUniv` — 웹 배치 화면에서 ON/OFF·수동 실행.

## 4. 매수 시점

위에서 내려와 **SMA20**에 닿을 때, **청산될 때까지 1회만**. 아래를 **모두** 만족해야 한다.

1. 직전 체결가 > SMA20, 현재가 ≤ SMA20 (**터치**) — 이 시점에는 주문하지 않는다
2. 터치 **이후 당일**에 **3분봉이 SMA20을 종가 돌파하고 양봉**(종가>시가)으로 끝나면 **SMA20 인근 호가 지정가** 매수. **10분** 안에 안 체결되면 잔량 취소(시장가 전환 없음). 날짜가 바뀌면 대기는 소멸하고 익일 재터치부터다
3. **다음날 장이 안 열리는 날**(금요일·연휴 전날)만 시각 < **14:00**. 다음 거래일이 바로 내일이면 정규장 마감까지 매수 가능
4. 수량 = `floor(매차금액 / SMA20 인근 호가)` (최소 1주)
5. **당일 전량 청산한 종목은 재매수 금지** (익일부터 다시 가능)

같은 이평을 다시 터치하면 확인 대기를 처음부터 다시 건다. 당일 3분 확인이 안 되면 그 터치는 소멸한다.

## 7. 백테스트 가정

- 원천: 전일 확정 일봉 SMA + `AI_MIN_STK_PRC` 1분봉 (없으면 일봉 근사)
- 터치: 직전 1분 종가 > SMA20 이고 당일 해당 분 저가 ≤ SMA20. 터치 즉시 매수하지 않음
- 1분봉을 3분봉으로 합쳐, **종가>시가·종가>SMA20** 양봉 돌파 후 SMA20 인근 호가 지정가. 이후 10분 동안 1분봉 저가≤지정가면 지정가 체결, 아니면 미체결 취소. 1분봉이 없으면 일봉 종가 회복 근사
- **+1.2%** 도달 시 보유 30%, **+2%** 도달 시 남은 보유 30%, **1차 또는 2차 후 0%(본전)** 잔량 손절, 익절 전 **−2%** 하드
- **수익 중 RSI14 ≥ 70** 이면 전량 (부분익절보다 먼저)
- 2차 후 잔량 **+4%** 이면 보유 50%(3차), **+7%** 이면 잔량 전량(4차)
- **당일 매수**가 15:18에 미수익이면 전량. 전일 이전 진입만 SMA20 손절
- 전량 청산 후 같은 날 재매수 없음
- **14:00 이후 신규 매수 금지는 다음날 장이 안 열리는 날만**
- **매일 15:15부터** 평단 0% 이상 3% 이하면 전량 (손실 제외, 3% 초과는 보유)
- 수수료 0
