# 마하세븐 눌림목 (정배열 + 윌리엄스 프랙탈)

- **stratId**: `mahaPullback_v1`
- **상태**: draft
- **스펙**: `strategies/specs/mahaPullback_v1.json`
- **권장 타임프레임**: 1분봉 (원천 적재). 3/5/15/30/60분은 1분 리샘플로 검증 가능
- **작성일**: 2026-08-02
- **출처**: [YouTube Shorts](https://youtube.com/shorts/3iUpKGBNq6g) / 관련 강의(스캘핑·1분봉·EMA 언급)

## 1. 개요

상승 추세(이평 정배열)에서 **20이평 눌림 → 매수 프랙탈 → 20이평 재돌파** 시 진입하는 단기 눌림목 전략.
손절은 단기 이평 이탈, 익절은 리스크 대비 고정 배수(손익비).

## 2. 필요 지표

| 지표 | 설정 | 비고 |
|------|------|------|
| 이동평균 | EMA 20 / 50 / 100 | 강의·실무는 **지수이평(EMA)** 이 일반적. SMA로 바꾸면 params의 `maType` 변경 |
| 손절용 이평 | EMA 5 | 요약본 기준. (일부 자료는 50선 손절 변형 있음 → 별도 버전) |
| 윌리엄스 프랙탈 | period=7 (민감 세팅) | 차트 도구 Input 기간 7. 엔진은 left/right 봉 수로 근사 |

직관용 색: 매수 프랙탈=녹색(또는 적), 매도 프랙탈=빨강 — 백테스트 로직에는 색 불필요.

## 3. 전제 조건 (Trend Filter)

- **정배열**: `emaFast > emaMid > emaSlow` (기본 20 > 50 > 100)
- 가격이 상승 추세 구간에 있다고 볼 수 있는 상태에서만 셋업 대기

## 4. 매수 시점

다음이 **순차**로 만족될 때 진입한다.

1. **눌림목**: 상승 중 가격이 `emaFast`(20) **아래**로 내려갈 때까지 대기
2. **신호**: 윌리엄스 프랙탈 **매수(다운 프랙탈)** 확정
3. **돌파·진입**: 가격이 다시 `emaFast`를 **위로 돌파**하는 캔들의 **종가**에 매수

상태 머신: `IDLE → WAIT_PULLBACK → WAIT_FRACTAL → WAIT_BREAK → IN_POSITION → IDLE`

## 5. 손절·익절

| 구분 | 규칙 |
|------|------|
| 손절 | 종가(또는 저가)가 `stopMa`(기본 EMA5) **아래 이탈** |
| 익절 | 진입가 기준, 리스크폭(`entry − stopPrice`)의 **`rrMult`배** (기본 1.5) |

진입 시점에 `stopPrice`를 확정하고 `takeProfit = entry + (entry - stopPrice) * rrMult` 로 고정하는 방식을 1차 구현 기준으로 한다.

## 6. 파라미터 (엔진 변수)

| 변수명 | 기본값 | 설명 |
|--------|--------|------|
| maType | ema | `ema` \| `sma` |
| maFast | 20 | 추세·눌림·돌파 기준 |
| maMid | 50 | 정배열 중간 |
| maSlow | 100 | 정배열 장기 |
| stopMa | 5 | 손절 이평 기간 |
| fractalPeriod | 7 | 차트 Input 기간(문서용). 엔진은 left/right 사용 |
| fractalLeft | 2 | 고전 프랙탈 좌측 봉 수 (period=7이면 구현 시 조정 가능) |
| fractalRight | 2 | 우측 확정 봉 수 (미래참조 방지) |
| rrMult | 1.5 | 손익비 배수 |
| stopUse | close | 손절 판정: `close` \| `low` |

## 7. 백테스트 가정

- 원천 데이터: **1분봉 OHLC** 적재 후, 필요 시 3/5/15/30/60분 리샘플
- 진입 체결가: 돌파 캔들 **종가**
- 청산 체결가: 손절·익절 조건 충족 봉의 **종가** (1단계). 이후 `high`/`low` 터치 시 우선순위 고도화 가능
- 수수료·세금: 1단계 생략 가능 (스펙 `fill.feeRate`로 확장)
- 프랙탈: `fractalRight` 봉이 끝난 뒤에만 신호 인정 (lookahead 금지)

## 8. 실전 주의

- 스캘핑 성격 → 일봉 검증만으로는 실전 성과를 보장하지 않음
- 전역 STLS(`tpr`/`slr`)와 병행 시 **전략 손절/익절 우선**을 권장 (스펙에 명시 후 엔진 반영)
- 동시호가·호가 공백·미체결로 종가 진입이 어긋날 수 있음
- 동일 종목을 여러 전략이 동시에 매수하지 않도록 슬롯/유니버스 분리
