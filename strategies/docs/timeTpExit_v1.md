# timeTpExit (TPX01) v4 - 시간대 분할익절·청산 스펙 (draft)

상태: **draft / paperOnly=true / enabled=false / stratLive=off**. 주문·라이브 연결 없음.

## 대상
- **매매등록(trade-on) 보유종목만** (qty>0). 전체 보유·LDR01 스카우트 목록 아님.
- **보유수량이 1주면 이 전략 전체에서 제외** (1·2·3차 익절, 익절 후 50% 청산, 20일선 1주 남김 청산 모두 안 함).

## 공통
- 수익률 = (현재가-평균매입가)/평균매입가×100 (수수료 제외)
- 매도수량 = floor(**체크 시점 남은 수량** × 비율), 계산이 1주 미만이면 **1주 매도** (단, 시작 보유 qty≥2인 경우만)
- 플래그(tp1/tp2/tp3)는 종목별 DB 저장

## 15:15 ~ 15:20 직전 (분할익절)
- 이 창 안의 현재 수익률만 판단 (장중 고점 무시)
| 단계 | 조건 | 매도 |
|---|---|---|
| 1차 | ≥10% & tp1 미실행 | 남은 수량 10% |
| 2차 | ≥20% & tp2 미실행 | 남은 수량 20% |
| 3차 | ≥30% & tp3 미실행 | 남은 수량 30% |
- 수익률 ≤0% → 1·2·3차 플래그 초기화
- 익절(1~3차 중 하나라도) 후 수익률 <0% → **남은 수량 50% 청산 먼저, 그 다음 플래그 초기화**
- 체크 순서: 마이너스 청산 → 리셋 → 1·2·3차 익절

## 15:19 ~ 15:20 (20일선 이탈)
- 이 구간 가격/수익률만 사용
- 현재가 < SMA20 음봉 이탈(현재가<시가, 전일종가≥SMA20) & 수익률 ≥10% → 1주만 남기고 매도
- 같은 틱에 겹치면 20일선 청산 우선

## 손실 매도 보호 (lossGuard, v4)
- 적용: 1·2·3차 익절, 익절 후 50% 청산, 20일선 청산 **모든 매도**
- 예상 실현손익 = (현재가-평균매입가)×매도수량 - 수수료/세금 < 0 이면 **주문하지 않음**
- 텔레그램 푸쉬: 종목, 매도사유, 매도수량, 현재가, 평균매입가, **예상손실금**, 수익률 + **진행할까요? (예/아니오)**
- 예 → 실행 직전 재계산 후 매도 / 아니오·무응답 → 매도 안 함(당일 같은 사유 재질문 없음)
- 50% 청산 보류 시 플래그 초기화도 응답 후 처리
