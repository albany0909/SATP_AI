# MMG01 수동정찰 종가 피라미딩 — 설계 (DRAFT rev3, 미커밋, enabled=false)

## 0. 개요
사용자가 대상 종목을 **1주 정찰매수**(HTS/MTS) → 프로그램이 매일 **장마감 직전 일봉 기준**으로 ADD/HOLD/부분익절/부분손절/EXIT 결정, 최대 3회 피라미딩. 장중엔 보호용 손절만.

## 1. 선행 수정 (MTS01 v64)
`maTouchLive.onBrokerFill` 체결선착 대기복구를 봇 주문번호·MTS01 관리종목으로 제한(수동 체결 오흡수 차단).

## 2. 대가 기법 매핑(일봉)
| 대가 | 적용 |
|---|---|
| O'Neil | 베이스 피벗 종가돌파 + 거래량 50일평균×1.5, 피벗+5% 이내만 매수, 손절 −7~8%, +20~25% 부분익절 |
| Minervini | 트렌드 템플릿(종가>50>150>200, 200 상승, 52주저점+30%, 고점−25% 이내), VCP, 상승 시에만 피라미딩, 추가 후 손절 상향 |
| Livermore | 수익 중일 때만 추가, 직전 추가가보다 높을 때만(최소저항선) |
| Darvas | 20일 박스 상단 종가돌파=추가, 박스 하단 이탈=손절 |
| Weinstein | 2단계만(SMA150≈30주선 상승 & 종가>SMA150), 종가<SMA150=전량 |

## 3. 레벨(일봉)
다바스 박스(20일, 상·하단 3일 확인), 스윙 피벗 좌3/우3(120일), 20/50일 베이스 고점, SMA10/20/50/150/200, ATR14. 0.25ATR·0.4% 이내 병합. 매일 15:10 산출.

## 4. 사이징(1주 정찰 → 목표 300만원)
- 추가 3회 비중 40% / 35% / 25% (목표액 300만원 기준: 120만·105만·75만)
- 수량 = min(트랜치금액/가격, 자산×0.5%÷(가격−손절가), 300만원 잔여) 내림, 최소 1주
- 조건: 평단 대비 +1% 이상, 직전 추가가 위, 추가 간 2거래일 이상, 셋업 종가 확정, 일손실 한도 미도달, 장중 추가 없음

## 5. EOD 결정(15:10 평가, 우선순위 순)
1. EXIT: 종가 < SMA50, 종가 < SMA150, 트렌드템플릿 2일 연속 실패(정찰 1주 포함)
2. PARTIAL_SL(1/2): 종가 < 최근접 지지/박스 하단
3. PARTIAL_TP(1/3): +20% 도달, 또는 클라이맥스(3일 +25% / 대량 갭 장대) 1/3
4. 트레일: 수익≥20%면 종가<SMA10, 아니면 종가<SMA20 → 1/2
5. ADD: 셋업 중 하나 — 피벗돌파 / VCP 돌파 / 다바스 박스돌파 / SMA10·20 눌림 양봉(거래량 감소 눌림)
6. HOLD

## 6. 손절
- 장중 보호: 평단 대비 −8% 재앙손절(시장가). 근거: O'Neil 7~8% 상한, 종가 결정 방식이라 장중 노이즈로 털리지 않게. 실제 위험은 셋업 손절(박스 하단·피벗 저점·SMA50) + 리스크 기반 수량으로 1.25%/종목 이내 제한(Minervini식 타이트 손절 효과)
- 추가 후 손절 상향: max(이전 손절, 추가 셋업 저점×0.99, 2차 추가 후 평단×0.97). +10% 이후 본전
- 정찰 1주는 장중 손절 제외(금액 미미)

## 7. 장마감 주문
- KRX: 15:20~15:30 종가 단일가. 15:20 이전 주문은 연속매매에서 체결됨
- 키움 REST trde_tp(코드 내 사용: 0 보통/지정가, 3 시장가). 문서 기준 기타: 5 조건부지정가, 6 최유리, 7 최우선, 61 장시작전 시간외, 62 시간외단일가, **81 장마감후 시간외(종가)**. 별도 "종가 동시호가" 코드는 없고, **15:20~15:30 중 0/3으로 넣으면 종가 단일가에 참여**. MSE01은 이미 15:18~15:19:59 시장가로 종가 직전 매수 중
- MMG01(rev3): 15:15 평가·주문 시작(15:15~15:20 연속매매 시장성 지정가, 미체결분은 15:20~15:28 동시호가로 정정) / 구안: 15:10 평가 → 15:21~15:28 지정가(매수 호가 내림/매도 호가 올림, 현재가 대비 ±2틱 여유) 제출, 동시호가 체결
- 15:29 이후 주문 금지 → 9/29 장후 SELL_FAIL(521790) 버그 회피
- 미체결: ADD는 취소·스킵, SL/EXIT는 익일 09:05 시장성 지정가 재시도. 81(장후 종가) 폴백은 옵션(기본 off, 모의 검증 후)

## 8. 계좌 리스크
총노출 ≤60%, 동시 6종목, 종목 리스크 ≤자산 1.25%, 일손실 −2% → 당일 ADD 없음, 월 −6% → MMG01 ADD 정지. 풀 종목 타 알고리즘 매수 차단, STLS 차단.
