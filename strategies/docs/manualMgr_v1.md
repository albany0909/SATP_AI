라이브 구현: `trading/manualMgrLive.py`, 판단 함수 `utils/mmgSignals.py`, 실적 `utils/mmgEarnings.py`.

## 1. 풀·진입
- 풀 = AI_ALG_STK(ALG_CD=MMG01) + 관심종목 표시(AI_WATCH_STK GRP_CD=MMG01, USE_TRADE=N).
  - 사용자: 텔레그램 `mmg add/del` (만료 없음). 스크리너: 16:10 장후 스캔, 최대 10종목, 10거래일(≈14일) 만료.
- 편입: 풀 종목의 **수동(봇 주문번호 아님)** 매수 체결 → MMG01 포지션. 기존 보유는 `mmg adopt 코드`.
- 자동정찰: 15:15 판단 시 E1~E4 신호 + 20일 평균 거래대금 ≥50억 + 주가 ≥1,000 + 실적(DART YoY≥20%/흑전) + 지수(KOSPI/KOSDAQ>SMA50) + 60일 재진입금지 → **1주**, ≤300,000원/주, 하루 ≤2종목.

## 2. 추가매수 (EOD만)
- Stage2(종가>SMA150 상승, SMA50>SMA150) + 평단 대비 **+5%** 이상 + 직전 매수가 위 + 종가>SMA50 상승 + 돌파(20일 고가·거래량 1.5배) 또는 눌림(SMA10/20) 셋업.
- 트랜치 40/35/25% × **종목당 최대 매수금액**(설정 탭, 기본 3,000,000원), 최대 3회, 간격 2거래일.
- 수량 = min(트랜치/가격, 위험 0.5%×자산/(가격−손절), 잔여 한도, 노출 60% 한도). 당일손익 −2% 이하면 추가 중지.

## 3. 청산
- 장중: 추가 1회 이상 포지션이 손절가 이하 → 시장가 전량 (정찰 1주는 장중 손절 제외 — 백테스트 동일).
- 손절가: 평단 −8% / 추가 후 평단 − 2·ATR14 / +10% 이후 평단 / **+50% 이후 max(평단, 고점×0.75)** (래칫).
- EOD 전량: 종가 < SMA50 또는 SMA150, 종가 < 고점 − 3·ATR, 종가 ≤ 손절가.

## 4. 주문·리스크
- 15:15 판단 → 15:21~15:27 지정가(매수 +2%/매도 −2% 여유, v63 호가 보정)로 종가 동시호가 참여. 장중 손절만 시장가(정규장).
- 최대 6종목, 노출 60%. 한 종목 한 전략: MTS01/MSE01 은 MMG01 풀·보유 종목 신규매수 스킵, MMG01 운영 중 STLS 시작 차단.
- 기록: AI_ALG_EVT(DECIDE/BUY_ORD/SELL_ORD/BUY/SELL), 원장, LIVE_TRADE(ALG_CD=MMG01), 일별 판단로그 `config/data/mmgDecision/YYYYMMDD.json`.
